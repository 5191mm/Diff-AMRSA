# Changelog

## 0.1.0 — Research source release

- Publish graph contrastive learning, retrieval-conditioned diffusion, and coordinate-refinement modules.
- Provide the molecular generation pipeline, data-preparation utilities, and component tests.
- Include the Diff-AMRSA model overview figure and module descriptions in the README.
- Exclude intermediate datasets, generated molecular outputs, checkpoints, and machine-specific configuration files.
- Provide Apache License 2.0 text, upstream licensing notices, citation metadata, and reproducibility guidance.
- Add CPU-based continuous integration checks for component tests, syntax, packaging, and release-file exclusions.

The release contains source code and component-level verification. It does not include complete trained checkpoints or claim reproduction of the paper's reported quantitative results.
